## 各類科知識點

App 的「學習」分頁依官方公告的應試科目與評鑑主題，把每張證照拆成科目、單元與知識點。每個知識點有講解、重點卡、常見誤區與依據來源，讀完可以直接做 CertGym 原創練習題。目前每個類科各有 8 個知識點、24 題原創練習題，持續增加中。

| 類科 | 考綱科目 | 知識點舉例 |
| --- | ---: | --- |
| iPAS AI 應用規劃師 初級 | 2 | 監督式、非監督式與強化式學習；過擬合、欠擬合與偏差變異權衡；分類模型評估：準確率、精確率、召回率與 F1 |
| 華語導遊 | 3 | 人員解說、非人員解說與解說人稱；導遊人員的執業條件與報備義務；臺灣的史前文化 |
| 華語領隊 | 3 | 旅客護照遺失的處理；行李延誤或遺失的處理（PIR）；銀行牌告匯率：買入、賣出與現金匯率 |
| 會計師 | 6 | 風險評估程序與查核風險模式；本量利分析與營業槓桿；暫時性差異與遞延所得稅 |
| 律師 | 4 | 正當防衛與誤想防衛；法律保留原則與授權明確性；消滅時效與除斥期間 |
| 護理師 | 5 | 給藥安全：三讀五對、醫囑縮寫與劑量計算；產後出血的定義、原因與處置；三段五級預防 |

## 在 App 裡怎麼練

App 分成「學習」「練習」「複習」「紀錄」「設定」五個分頁。

| 想做的事 | 在 CertGym 的做法 |
| --- | --- |
| 先搞懂觀念 | 在「學習」分頁依考綱讀知識點，讀完直接做對應的原創練習題 |
| 熟悉單一科目 | 在「練習」分頁選類科、梯次與科目，自訂每回題數 |
| 檢驗整體實力 | 選定梯次，把題數調到整份考卷，作答完看正確率、及格判定與逐題明細 |
| 利用零碎時間 | 在練習範圍選單點「用閃卡複習」，先想答案再翻面 |
| 補強弱點 | 答錯的題目自動進入「複習」分頁的待複習清單，連續答對兩次才算精熟 |
| 整理重點題目 | 收藏題目並分到自訂集合，整個集合直接開始練習 |
| 追蹤進度 | 在「紀錄」分頁查看連續天數、正確率與作答明細 |
| 每天維持手感 | 開啟每日一題提醒，設定時間與出題範圍 |

解析內容主要由 AI 輔助生成，僅供參考。發現題目或解析有誤，歡迎從 App 的「設定 → 意見回饋」回報。
