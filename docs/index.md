## 在 App 裡怎麼練

| 想做的事 | 在 CertGym 的做法 |
| --- | --- |
| 熟悉單一科目 | 進入道館，選梯次與科目，自訂每回題數 |
| 檢驗整體實力 | 選定梯次，把題數調到整份考卷，作答完看正確率、及格判定與逐題明細 |
| 利用零碎時間 | 用閃卡複習同一份題庫，先想答案再翻面 |
| 補強弱點 | 答錯的題目自動進入待複習清單，連續答對兩次才算精熟 |
| 整理重點題目 | 收藏題目並分到自訂集合，整個集合直接開始練習 |
| 每天維持手感 | 開啟每日一題提醒，設定時間與出題範圍 |

解析主要由 AI 輔助生成，僅供參考。發現題目或解析有誤，歡迎從 App 的「設定 → 意見回饋」回報。
